# 🚢 Titanic Survival Analysis

A complete Exploratory Data Analysis (EDA) project on the famous **Titanic Dataset**, aiming to uncover the key factors that influenced passenger survival using Python, data visualization, and statistical analysis.

---

## 📌 Project Overview

The sinking of the RMS Titanic is one of the most well-known maritime disasters in history. This project explores the dataset to identify the characteristics that affected passengers' chances of survival.

The analysis includes:

* Data Cleaning
* Data Preprocessing
* Feature Engineering
* Exploratory Data Analysis (EDA)
* Data Visualization
* Insights & Conclusions

---

## 🎯 Objectives

* Understand the structure of the dataset.
* Handle missing values and duplicate records.
* Explore relationships between different passenger attributes.
* Identify the most influential factors affecting survival.
* Create clear and informative visualizations.

---

## 📂 Dataset

The dataset contains passenger information such as:

* Passenger ID
* Survival Status
* Passenger Class
* Name
* Sex
* Age
* Number of Siblings/Spouses
* Number of Parents/Children
* Ticket Number
* Fare
* Cabin
* Embarked Port

---

## 🔍 Key Insights

* **Female passengers had a significantly higher survival rate than males.**
* **Passengers traveling in First Class were more likely to survive than those in lower classes.**
* **Children generally had better survival chances than adults.**
* **Passengers who paid higher fares tended to have higher survival rates.**
* **Family size showed an impact on survival, while very large families had lower survival rates.**
